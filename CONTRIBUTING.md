# Contributing to BhojpuriPy 🌾

First off, thank you for considering contributing to **BhojpuriPy**! It's people like you that make the Indic NLP community great.

## Ways to Contribute

1. **Vocabulary Expansion**: Suggest authentic Bhojpuri terms, idioms, or colloquialisms.
2. **Regional Dialect Data**: Contribute dialect rules for Western (Purvanchal), Standard (Bhojpur), or Northern (Saran) regions.
3. **Bug Reports**: Open an issue detailing unexpected translations or edge-case script issues.
4. **Documentation**: Improve guides, translations, or example scripts.

## Contribution Guidelines

1. **Fork the repo** and create your branch from `main`.
2. Ensure your code passes all lint and unit checks.
3. Format python code with PEP 8 standards.
4. Write clear, descriptive commit messages.
5. Open a Pull Request referencing any related issues.

## Code of Conduct

By participating, you agree to uphold our [Code of Conduct](CODE_OF_CONDUCT.md).

Thank you for helping Bhojpuri technology thrive! ❤️
